# AI-Customer-Support-Chatbot
AI-powered customer support chatbot using Python, NLP, LLM and FastAPI.
## Overview

An AI-powered customer support chatbot designed to process customer
queries and generate relevant responses using NLP and an AI language model.

## Features

- Customer query processing
- Natural language understanding
- AI-generated responses
- Context-aware conversations
- REST API integration
- FastAPI backend

## Technologies

- Python
- NLP
- LLM
- FastAPI
- REST API
